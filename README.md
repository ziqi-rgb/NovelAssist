# AI 小说辅助引擎 (NovelAssist)

面向网文/长篇创作的 AI 辅助写作工具。核心是用 **AI 推理链（土法自定义推理流程）** 自动构建和维护世界观（地点/人物/势力/大纲/时间线），并在写作过程中持续保持设定一致性。

## ✨ 核心亮点：AI 推理链

项目最核心的能力，是把"建纲、建人设、建地图"这类复杂创作任务，编排成**可视化的节点图流水线**，由 AI Agent 通过 function calling 自动执行：

**规划 → 创建 → 校验 → 修正 → 写入 → 验收**

- 每个节点由 AI 自主完成（生成内容、调用工具写库、比对校验），不合格自动进入修正循环，直到通过
- 流水线带**待办清单**和**分支判断**，多路任务可并行推进
- 内置 3 条系统推理链：

| 推理链 | 用途 |
|--------|------|
| 🗺️ **蓝图规划与逐层搭建流** | 自顶向下构建地图：大千世界 → 宇宙 → 星球 → 大陆 → 国家 → 城池 → 街区 → 建筑，8 级层级逐层铺开 |
| 👤 **严谨人设与模板质检流** | 按人物模板批量生成角色属性，逐字段校验与模板吻合，不达标自动修正 |
| 📖 **全维世界观与大纲流水线** | 世界观/势力/地理/人物/能力体系分类生成大纲，支持父子嵌套 |

推理链可自由创建、覆盖、可视化编辑，是整套工具的中枢。

## 🗺️ 世界观管理

- **地点**：8 级尺度层级树 + 25×25 网格坐标，属性沿父级继承，坐标冲突自动修复
- **人物**：结构化属性（按模板分组）、状态流转（存活/阵亡/飞升/失踪/退场）、变更自动留存快照
- **势力**：成员归属与职位身份
- **大纲**：6 大分类（世界观/世界势力/地理/能力体系设定/人物设定/剧情大纲）
- **时间线**：正文 / 历史 / 世界 三条独立时间线，事件关联参与人物与地点

## ✍️ 写作辅助

- **断点续写**：在正文任意光标位置续写，结果直接插入光标处；也可选中片段，让 AI 围绕选中内容续写
- **正文归档**：把写好的片段归档，AI 自动提取时间线事件、更新人物属性与状态、处理势力变更与位置移动，世界设定随写作自动演进

## ⏳ 时空引擎

tick 制世界日历，正文中的【时间流逝】标记驱动时间推进；人物有作息规律与移动轨迹，可推算"谁此刻在哪里"。（辅助功能，不做赘述）

## 🗂️ 项目管理

支持多小说项目，每个项目独立世界观；分卷 + 章节结构，正文与归档内容分离。（基本功能）

## 🚀 快速开始

```bash
# 环境：Python 3.11+，需要 OpenAI 兼容的 LLM API（OpenAI / DeepSeek 等）

pip install -r NovelAssist/backend/requirements.txt   # 安装依赖

cd NovelAssist
cp .env.example .env          # 复制配置模板，填入 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL
cd ..

python run.py                 # 启动，自动打开 http://127.0.0.1:8000
```

数据默认存储在 `.data/novel.db`（SQLite），**请定期备份**。

## 🛠️ 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Python 3.11 + FastAPI + Uvicorn |
| 数据库 | SQLite + SQLAlchemy 2.0 |
| AI | OpenAI SDK（function calling + 推理链） |
| 前端 | 原生 HTML / JS / CSS（无框架、无构建步骤） |
