用语映射表
═══════════════════════════════════════

节点类型:
  推理 = reasoning       (AI输出内容+路由标记)
  路由 = router          (匹配上一节点路由值)
  写入 = write           (程序直写数据库)
  提问 = ask             (暂停询问用户)

输出格式:
  地点 = location | 角色 = character | 大纲 = outline
  (不写 = 自由文本)

写入目标:
  待办清单 = chain_todos
  地点    = location
  角色    = character
  势力    = faction
  大纲    = outline

待办清单的写入操作:
  新建     = create (field: content)
  标记完成 = update (field: status) → 自动找第一项pending标记为done

路由条件:
  继续/完成  = CONTINUE/DONE
  是/否     = YES/NO

层级（地图链）:
  世界 = 大千世界 | 星球 = 星球+大陆 | 国家 | 城池 = 城池+街区

模块（大纲链）:
  世界观 | 势力 | 地理 | 人物(简略) | 能力
